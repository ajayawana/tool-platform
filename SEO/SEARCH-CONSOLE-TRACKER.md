## Decision rules

- High impressions + low CTR: improve title/search description and page intent match.
- Impressions + average position around page 1-3: strengthen the page with genuinely useful supporting content and internal links.
- Queries that are relevant but not explicitly covered: add a concise section answering that intent.
- Indexed with near-zero impressions: do not automatically build more pages; wait for sufficient data and check query demand.
- Strong query/page combination: consider a dedicated supporting tool only when it serves a distinct intent.

Never treat a low competition assumption as verified until search results and Search Console data support it.
